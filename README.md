# Personal-Portfolio1
Personal Portfolio
This is a simple and responsive personal portfolio website created using HTML, CSS and JavaScript. It presents a brief introduction and showcases my projects, education background, technical skills, and contact information.

Features
1.Profile section with a typing effect for displaying different roles
2.Navigation bar for easy access to each section
3.About section describing my background and interests
4.Projects section listing some of the real-world applications I have built
5.Education section showing my academic qualifications
6.Skills section displaying the technologies and tools I have worked with
7.Contact section with links to email, LinkedIn and GitHub

Technologies Used
1.HTML
2.CSS
3.JavaScript

How to Use
Clone or download this repository
Open the index.html file in your browser
Explore the different sections of the portfolio

Folder Structure
/index.html
/style.css
/script.js
/README.md

Description
This portfolio is designed to provide a quick and clear overview of who I am and what I can do. It is intended for recruiters, peers, and anyone interested in learning about my projects and skills. Every section is organized to highlight key points and make information easy to access.
